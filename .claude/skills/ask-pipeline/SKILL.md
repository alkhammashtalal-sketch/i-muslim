## 5. البنية التقنية (ثابتة)

| الجزء | الاختيار |
| --- | --- |
| الواجهة | Vite + React + TypeScript، `vite-plugin-pwa`، خط IBM Plex Sans Arabic مستضاف ذاتيًا (حزمة `@fontsource`، رخصة OFL) لا من خوادم خارجية |
| الخادم | Cloudflare Worker واحد يقدّم ملفات الواجهة (Workers Static Assets) ومسارات `/api/*`. إن تعذّر ذلك فـ Pages + Worker، وأبلغ |
| التضمين | Workers AI `@cf/baai/bge-m3` (1024 بُعدًا)، النموذج نفسه للفهرسة ولسؤال المستخدم |
| الفهرس | Cloudflare Vectorize، الاسم `imuslim-passages`، 1024 بُعدًا، `cosine` |
| قاعدة البيانات | Cloudflare D1، الاسم `imuslim`: المقاطع، وجدول FTS5 للبحث بالكلمات، والكاش، والأسئلة الشائعة، والحدود |
| النموذج اللغوي | **DeepSeek V4 Flash مستضافًا على Cloudflare Workers AI** (`@cf/deepseek-ai/deepseek-v4-flash-0731`) عبر ربط `AI` الموجود، بلا حساب DeepSeek ولا مفتاح، ويُحاسب على خطة Workers Paid (قرار 5 أكتوبر بعد تعذّر فتح حساب DeepSeek؛ الأمر 15). الإعداد في `worker/src/config/llm.json`: `provider` = `workers-ai`، `model`، `temperature` = 0، `maxTokens` = 700. مسار `openai` (DeepSeek المباشر بمفتاح `LLM_API_KEY`) يبقى بديلًا من الملف نفسه |
| الخطة | Cloudflare Workers Paid (5 دولارات شهريًا)، لأن فهرسة القرآن كاملًا تتجاوز 5 ملايين بُعد المجانية |

**مسار السؤال `POST /api/ask` بالمدخلات `{ q, lang, simple }`:**

1. تحقق من المدخل (حتى 500 حرف) والحد اليومي: بصمة SHA-256 لعنوان IP مع ملح يومي سري، ولا يُخزَّن العنوان نفسه.
2. تطبيع السؤال في نسخة بحث فقط.
3. بوابة المستوى بلا نموذج: أنماط واضحة لـ ج ود (حالة شخصية، طلاق، ميراث محدد، تكفير، خلاف طائفي، «هل يجوز لي في حالتي»…) ← إحالة فورية.
4. الكاش لأسئلة أ وب (تطابق تام ببصمة السؤال المطبّع + اللغة)، ثم مطابقة الأسئلة الشائعة المعتمدة.
5. الاسترجاع: bge-m3 في Vectorize (أفضل 20) + FTS5 (أفضل 20) ← دمج بطريقة Reciprocal Rank Fusion ← أفضل 5. تحت العتبة ← اعتذار بلا استدعاء.
6. استدعاء واحد للنموذج يعيد JSON: `level`، `answerable`، `used_passages`، `direct_answer` مع شواهده، `explanation` جملًا كل منها بشواهدها.
7. التحقق (القاعدة 6 أعلاه)، ثم بناء البطاقة من نصوص D1، ثم تخزين أ وب في الكاش، ثم تسجيل الاستهلاك.
8. السقف الشهري العام: عند بلوغه تتوقف الاستدعاءات ويبقى الكاش والأسئلة الشائعة تعمل.
