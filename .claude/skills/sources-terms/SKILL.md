## 2. القاعدة 1 — المصادر ثوابت لا تُمس

ممنوع: اقتراح مصدر، أو رابط، أو استبدال رابط، أو إضافة كتاب، أو استخدام أي مجموعة بيانات من GitHub أو Kaggle أو Hugging Face أو غيرها للنصوص الشرعية. أي شرح أو مثال يكون من داخل هذه القائمة فقط.
**إذا لم يعمل رابط، أو لم تجد مصدرًا، أو لم تُقرأ صيغة ملف: توقف، واكتب ما حدث بالضبط، واسأل. لا تقترح بديلًا.**

نطاق شرح الحديث (قرار طلال 9 أكتوبر): رياض الصالحين كاملًا (العبادات والأخلاق والأذكار) بعد إذن (ز)، لقوله «الأوسع للمستخدم».

نطاق الفهرسة: ما يغطي المستويين أ وب — التعريف بالإسلام، أركان الإيمان والإسلام، الطهارة، الصلاة، الصيام، الزكاة، الحج، الأخلاق، أسئلة غير المسلمين والمسلمين الجدد. القرآن مع تفسيريه وترجمته يُفهرس كاملًا بمستوى الآية (القرار المعمول به حتى يقرر طلال غيره). أي توسيع آخر يمر على طلال.

**إضافة (الملحق 0072-add50 §3، 26 أكتوبر):** تُضاف إلى الفتاوى المسماة في (د) فتوى ابن باز 11916، تحت الإمساكية (جدول رمضان)، بنصها ورابطها.
