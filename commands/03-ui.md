# الأمر 3 — الواجهة كاملة ببيانات تجريبية (النافذة 1 بعد نجاح الأمر 1، نحو ساعتين)

**الدور:** أنت مطور واجهات أول ومصمم تجربة مستخدم، خبير في التطبيقات العربية من اليمين لليسار وفي الإتاحة.

اقرأ `CLAUDE.md` و`docs/SCREENS.md` وملفات `design/*.dc.html` قبل البدء.

**الهدف:** واجهة «i مسلم» كاملة بكل عناصر `docs/SCREENS.md` وحالاتها، تعمل الآن على بيانات تجريبية، بحيث يكفي لاحقًا تبديل مصدر البيانات إلى `/api/ask` الحقيقي.

**المستفيد:** غير المسلم والمسلم الجديد على جواله، بعشر لغات؛ ولجنة التحكيم التي تفتح الرابط من جوال أو حاسوب.

**السياق:** الهيكل والنشر جاهزان من الأمر 1. محرك الإجابة يُبنى لاحقًا (الأمر 6) بالعقد أدناه. التصاميم الجديدة من طلال قد تصل لاحقًا؛ ابنِ الآن على النماذج الموجودة ورموز التصميم.

**العقد بين الواجهة والخادم** (ضعه في `shared/api.ts` واستورده من الطرفين):

```ts
export type Lang = 'ar'|'en'|'ur'|'id'|'ms'|'tr'|'fr'|'es'|'bn'|'hi';
export type AskRequest = { q: string; lang: Lang; simple?: boolean };
export type Cite = string; // رقم مقطع مثل "quran:2:255"
export type Sentence = { text: string; cites: Cite[] };
export type Quote = { id: Cite; kind: 'ayah'|'hadith'|'aqeedah'|'fatwa'; text: string; text_en?: string; ref: string; url: string; verified: boolean; grade?: string };
export type AnswerResponse = { type: 'answer'; level: 'A'|'B'; direct: Sentence; quotes: Quote[]; explanation: Sentence[]; tafsir?: { name: string; ref: string; url: string }[]; machineTranslated: boolean; reviewed?: { by: string; at: string }; fromCache: boolean };
export type ReferralResponse = { type: 'referral'; level: 'C'|'D'; message: string; link: string };
export type AbstainResponse = { type: 'abstain'; message: string; link: string };
export type ErrorResponse = { type: 'error'; code: 'rate_limited'|'monthly_cap'|'bad_input'|'server'; message: string };
export type AskResponse = AnswerResponse | ReferralResponse | AbstainResponse | ErrorResponse;
```

**القيود:**
- كل ما في `CLAUDE.md` الأقسام 3 و4 و8. النصوص الثابتة في `docs/SCREENS.md` حرفيًا.
- البيانات التجريبية في `web/src/mock/` وتوسم بوضوح أنها تجريبية، ونصوصها الشرعية مأخوذة من أمثلة النماذج في `design/` فقط؛ لا تكتب آية أو حديثًا من عندك.
- عشر لغات: ملفات ترجمة لنصوص الواجهة، العربية والإنجليزية بعناية، والثماني الباقية ترجمة آلية موسومة. `dir` يتبدل حسب اللغة.
- لا تخزين على الخادم للمحادثة. الإعدادات فقط في `localStorage` محاطة بـ try/catch.
- لا تحليلات ولا متتبعات ولا خطوط من خوادم خارجية.
- الإتاحة: تباين AA، تسميات لقارئ الشاشة، تركيز مرئي، أهداف لمس 44 بكسل على الأقل، احترام تكبير الخط.

**الخطوات:**
1. رموز التصميم (فاتح وداكن) ومكونات: الشريط العلوي، الفقاعة، البطاقات الثلاث، الشارات، اللوحة المنبثقة، الحقل.
2. العناصر 1–15 في `docs/SCREENS.md` كلها، وكل حالة يمكن الوصول إليها من البيانات التجريبية (سؤال تجريبي لكل نوع رد).
3. تعليمات التثبيت في iPhone، وزر التثبيت في Android.
4. نسخة الحاسوب بعمود في الوسط.
5. إن تيسّر: صور للشاشات الرئيسية بمقاس 390×844 في `docs/screenshots/` (عربي وإنجليزي وأردي، فاتح وداكن) — نحتاجها للعرض والـ README.
6. نشر على الرابط الحي، وفحص على جوال حقيقي.

**معيار النجاح:**
- كل عناصر `docs/SCREENS.md` موجودة، وكل نوع رد (إجابة، إحالة، اعتذار، خطأ) يظهر من سؤال تجريبي.
- تبديل اللغات العشر يعمل، والاتجاه صحيح في العربية والأردية.
- التطبيق يُثبَّت على الشاشة الرئيسية ويفتح بملء الشاشة.
- لا نص لاتيني داخل الواجهة العربية، ولا أخطاء في وحدة التحكم.

**طريقة التسليم:** تقرير بالعربية حسب القسم 10 من `CLAUDE.md`، مع الرابط الحي وصور الشاشات إن وُجدت.
