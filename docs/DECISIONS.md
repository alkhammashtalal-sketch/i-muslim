# سجل القرارات التقنية

قرارات اتخذها المنفّذ (Claude Code) بتفويض من طلال بتاريخ 5 أكتوبر 2026: «أي قرار تقني لا يخص المصادر اتخذ الأنسب وسجّله». لا شيء هنا يمس المصادر أو شكل الإجابة أو سياسة المستويات أو نصوص الإحالة والاعتذار.

## الأمر 01 — الهيكل والنشر

| # | القرار | السبب |
| --- | --- | --- |
| 1 | إعداد Wrangler بصيغة `worker/wrangler.jsonc`، والـ Worker يقدّم `web/dist` عبر Workers Static Assets مع `not_found_handling: single-page-application` و`run_worker_first: ["/api/*"]` | Worker واحد كما في القسم 5، وكل مسار غير `/api` يرجع إلى `index.html` |
| 2 | ربط D1 باسم `DB` وVectorize باسم `VECTORIZE` وWorkers AI باسم `AI` | أسماء ربط ثابتة تستعملها الأوامر التالية |
| 3 | معرّف قاعدة D1 مكتوب في `wrangler.jsonc` داخل المستودع | المعرّف ليس سرًا ولا يمنح وصولًا بدون حساب Cloudflare؛ والأسرار تبقى عبر `wrangler secret put` |
| 4 | رابط العمل الحالي `https://i-muslim.alkhammashtalal.workers.dev` (نطاق workers.dev الافتراضي) | لا نطاق مخصص مطلوب الآن |
